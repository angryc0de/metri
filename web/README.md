# Metri · 减脂记录（Web 版）

完全本地的减脂热量记录工具。无账号、无服务器、无上传 —— 你的所有记录只存在这台设备的浏览器里，随时可以导出带走。

## 它解决什么问题

减脂期最需要的是「今天吃没吃对」，而不是复杂的身体数据分析。Metri 只做三件事：

1. **记饮食** —— 内置 29 种常见食物（按份/克两种记法）；库里的没有，就直接描述「牛肉减脂便当」，自动拆解成「杂粮饭 140g / 水煮蛋 50g / 卤牛肉 110g / 西兰花 120g / 烹调油 8g」共 453 kcal，逐项核对、可调份量倍数。
2. **记训练** —— 47 个力量器械 + 10 种有氧，全部按 MET 实时计算：负重越大 MET 越高、同样 30 分钟坡度 10% 和坡度 0 的爬坡走消耗差近一倍，且扣除训练时段的静息消耗（否则和全天基础代谢重复计算）。
3. **看缺口** —— 日历一眼看出哪天有缺口（绿）、哪天吃超了（红）、哪天只练没吃（灰点）；周汇总告诉你平均缺口离目标差多少、达标几天。日历上滑时，选中日期所在的那一周固定吸顶，后面的记录继续滚。

## 怎么用

1. 打开链接，填写性别 / 年龄 / 身高 / 体重（或者点「不想填，先看示例数据」直接体验完整功能）
2. 填完资料进门后是一条**干净的空白时间线**，从今天开始记自己的；想直接看完整效果，可以在引导页点「不想填，先看示例数据」，或用 `?demo=1` 打开
3. 底部三个页签：**训练 / 饮食 / 我**
4. 每个列表右上角的「+」添加记录；弹层里的参数都可以按 ± 调整，改完立即看到净消耗预览
5. 「我 → 数据」可以导出 JSON 完整备份，或 5 个 CSV（每日汇总 / 力量 / 有氧 / 饮食 / 体重）

## 中英双语

- 语言**自动跟随浏览器**：系统语言是中文就显示中文，否则显示英文（词典覆盖全部界面、47 个器械、29 种食物、10 种有氧与拆解提示语）
- 也可以用 `?lang=en` 或 `?lang=zh` 强制指定，方便截图和演示
- 中文原文即词条 key，查不到自动回退中文，不会出现漏翻的裸 key

## 数据与隐私

- 所有数据用 localStorage 存在本设备，不上传任何服务器，也没有账号体系
- 清理浏览器数据会连记录一起消失 —— 建议每周在「我 → 数据」导出一次 JSON 存到网盘
- 换设备：导出 JSON → 新设备导入，完整还原

## 技术说明

- 纯静态 HTML + CSS + 原生 JavaScript，**零依赖、零构建**，任何静态托管都能跑
- 计算口径（Mifflin-St Jeor BMR / MET 净消耗 / 目标缺口 / 自适应 TDEE 线性回归 / 异常取中位数）与同项目的 **Android 版逐条对齐**，由同一组单元测试期望值守护（`tools/check-web.js`）
- 蛋白质目标、缺口警示开关、黑夜 / 白天双主题（语义色只降明度不换色相）与 Android 版行为一致
- 端到端测试：`tools/e2e.js`（Edge CDP 驱动，断言覆盖引导 → 空白进门 / 示例数据 → 记录 → 拆解 → 导出 → 换肤 → 持久化 → 中英双语）；`tools/check-i18n.js` 静态校验所有 `T()` 词条都有英文翻译

## 与 Android 版的关系

同一名「Metri」，两份实现：Android 版（Kotlin + Jetpack Compose + Room，见同仓库 app/）面向日常长期使用；Web 版面向即开即用与分享。两者共享同一套计算口径与产品形态（日历吸顶、双主题、拆解式饮食记录），数据模型同构（日期均为 epochDay），备份 JSON 可以互相导入。
